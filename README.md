用大模型和 AI Agent 重新思考地图应用：从空间数据处理、地图服务到前端可视化，打通 **AI × GIS** 全链路。
Rethinking map apps with LLMs and AI agents, end to end from spatial data and map services to front-end visualization.

## 🧠 我在做什么 What I'm Building

- **AI + 地图交互**：用自然语言查地图、出专题图、做空间分析 / Natural-language map queries, thematic maps and spatial analysis
- **GIS Agent / MCP 工具**：让大模型能直接调用 GeoServer、空间数据库和地图服务 / Letting LLMs call GeoServer, spatial databases and map services directly
- **GIS 全栈工程化**：数据入库、服务发布、前端组件一条龙 / Data ingestion, service publishing and front-end components in one pipeline
- **AI 辅助开发**：用 Cursor、Codex 等 AI 编程工具提效 / Shipping faster with AI coding tools
